# 验证说明

## 可重复的本地检查

```bash
npm ci
npm run check
npm run package
```

自动测试不调用真实灵矽接口、不读取用户 API 密钥。覆盖规则与 90 局模拟、私密视角、独立座位绑定、合法动作校验、投票隔离、失败回滚、猎人技能、WebSocket 遮罩 / 分片 / 控制帧 / 打断、PCM 重采样、ASR 手动录音协议、WAV 与 Ogg Opus 封装。

GitHub Actions 在 Node.js 22 和 24 上执行格式检查、测试和源码打包。实际云端执行结果以仓库 Actions 页面为准。

## 手动验收

1. 无密钥启动项目，确认模拟模式可进入 6 / 9 人局并完成夜间、发言、投票和结局流程。
2. 完成 `npm run linx:init`，启动服务，在未进行对局时检查全部智能体，确认 8 位玩家均返回真实输出。
3. 在设置逐个试听音色；在对局中检查 AI 发言、字幕、重听和播放取消。
4. 授权麦克风，录音后检查转写与手动提交；再检查拒绝权限、静音、取消录音时的提示和麦克风释放。
5. 模拟网络失败，确认错误明确、可重试，未发生部分阶段结算。

## 既有真实联调记录

2026-10-24 已完成 8 个独立玩家的设备绑定、OTA / WSS 连接及结构化输出验证；9 人真实对局首轮夜间、发言、投票与结算通过。独立 ASR 通道通过公开语音样本转写，内嵌浏览器可授权并进入录音状态。转写仍有个别词遗漏，需要人工检查。

8 种音色均通过配置回读和真实合成，本轮实际返回 PCM / WAV；Ogg Opus 封装有自动测试覆盖，未在该轮真实平台响应中覆盖。网页音色列表与试听已验证。

以上为指定日期的集成验证，不保证其他账号的权限、模型、音色可用性或后续平台变化。每个新安装仍应执行手动验收。测试记录不包含账号密钥、设备 ID 或私密对局内容。
