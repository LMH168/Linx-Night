# 月隐 Moonveil

基于灵矽 AI 的网页语音狼人杀。一个真人与 5 / 8 个 AI 玩家同桌，每位 AI 使用独立智能体、虚拟设备、人设与音色，无需实体硬件。

支持 6 / 9 人练习局、夜间技能、轮流发言、投票、猎人开枪、私密笔记与复盘。语音输入由网页采集、灵矽识别，转写后手动提交；AI 发言由灵矽合成，主持人使用浏览器朗读。

## 快速体验

需要 **Node.js 22.9+**（推荐 24 LTS）和 npm，推荐使用 Chrome / Edge。运行时没有第三方 npm 依赖；开发依赖 Prettier。

在项目根目录执行：

```bash
npm ci
npm start
```

打开 [http://localhost:4173](http://localhost:4173)。未配置密钥时使用本地模拟玩家，适合先体验游戏规则。灵矽语音输入和 AI 专属音色需要完成下方配置。

`npm start` 同时启动游戏服务（4173）与语音服务（4174），仅监听本机 `127.0.0.1`。关闭时按 Ctrl+C。网页目前固定访问语音端口 4174，请保留该端口。

## 接入灵矽

1. 将 `.env.example` 复制为 `.env`（macOS / Linux 可运行 `cp .env.example .env`）。
2. 用编辑器在 `.env` 填写自己的 `LINX_API_KEY`，保留 `AI_MODE=auto`。
3. 初始化账号资源：

   ```bash
   npm run linx:init
   ```

   此命令依次创建并绑定 8 个 AI 玩家、1 个独立语音识别智能体及其虚拟设备，然后为 8 个玩家设置不同音色。它会调用你的灵矽账号；实际调用费用以平台计费为准。

4. 运行 `npm start`；如已启动则重启。进入网页设置，点击“检查全部智能体”，通过后开始游戏。

初始化进度保存在 `.linx/players.json`，中断后可重新运行。请保留该目录以复用本次安装资源；删除它后重新初始化会创建一套新资源。脚本不会自动删除云端资源，也不修改其他安装的智能体。

需要单独配置时：

| 命令                  | 用途                           |
| --------------------- | ------------------------------ |
| `npm run linx:setup`  | 创建 / 恢复 8 位玩家及设备绑定 |
| `npm run linx:asr`    | 创建 / 恢复独立语音识别通道    |
| `npm run linx:voices` | 设置 8 种音色并回读核验        |

密钥只放在服务端 `.env`；账号资源保存在 `.linx/`，两者均不进入 Git 或源码包。前端不接触 API 密钥或设备 token。换账号时应使用新的项目目录重新初始化。

## 模式与语音

| `AI_MODE` | 行为                                                   |
| --------- | ------------------------------------------------------ |
| `auto`    | 无密钥使用模拟；有密钥要求灵矽配置完整，失败时明确报错 |
| `demo`    | 使用本地规则模拟玩家                                   |
| `linx`    | 强制使用灵矽，缺少配置时报错                           |

一套设备同时支持一局灵矽对局。进行中的灵矽对局可刷新页面恢复；服务重启会清除内存对局。先结束对局，再检查全部智能体。

- 点击“语音输入”开始录音，再点一次结束并识别，最长 60 秒。检查转写文字后手动提交。
- 麦克风需要浏览器和操作系统授权；当前网页通过 localhost 使用麦克风。
- 网页设置可试听每位 AI 音色，对局中可重听最近的 AI 发言。
- 录音在内存中处理，提交至灵矽识别，不写入本地录音文件。语音失败会显示错误，可改用文字输入。
- AI 发言先生成文字，再合成同一段音频，因此有额外 TTS 调用。实际响应速度由平台决定。

| 玩家 | 默认音色   |
| ---- | ---------- |
| 林间 | 沉稳质感男 |
| 阿雾 | 元气甜美女 |
| 北辰 | 智慧青年男 |
| 小鹿 | 温柔闺蜜女 |
| 夜航 | 热血磁性男 |
| 知更 | 积极知性女 |
| 白榆 | 低调冷静女 |
| 拾光 | 磁性低音男 |

音色从平台列表按名称选择；若平台调整名称或可用范围，初始化会提示具体缺失音色，可调整 `scripts/setup-voices.mjs` 的选择列表。

## 玩法边界

6 人局：2 狼、预言家、女巫、2 村民。9 人局：3 狼、预言家、女巫、猎人、3 村民。

采用屠边胜负；女巫不可自救、每晚一药；不允许自刀和投自己；平票无人出局；无警长和遗言阶段。模型只提出动作，裁判校验并结算；AI 发言可以包含策略性谎言或推理错误。

当前为本机单人练习原型，没有用户认证、多人房间或对局持久化。**不能仅上传 GitHub Pages 就运行**，需要 Node.js 后端。公网服务还需增加认证、会话权限、限流、持久化及统一 HTTPS 入口。

## 开发与验证

```bash
npm test                 # 无需 API 密钥的自动测试
npm run format           # 统一代码格式
npm run check            # 格式检查 + 自动测试
npm run package          # 导出干净源码目录与 ZIP（另需 Python 3）
```

源码导出位于 `dist/moonveil-source/` 和 `dist/moonveil-source.zip`。打包使用明确的源码清单，排除密钥、设备状态、依赖和运行产物，并检查密钥特征。打包不会上传任何内容。

自动检查在 GitHub Actions 的 Node.js 22 / 24 上运行，不使用灵矽凭据。详见 [验证说明](docs/validation.md)。

```text
.github/workflows/ci.yml   GitHub 自动检查
```
