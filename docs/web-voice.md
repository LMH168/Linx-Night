# 灵矽网页语音（#68）

## 配置

独立软件身份 `web-voice` 用于网页转写和公共播报，不可复用 `LINX_PROFILES` 的游戏玩家。先运行 `node scripts/linx-client.mjs init web-voice`、`node scripts/linx-client.mjs activate web-voice`，在控制台把激活码关联到独立语音 Agent。该 Agent 无记忆、无需绑定游戏 MCP，不应关联其他可写业务工具。然后设置 `LINX_VOICE_PROFILE=web-voice` 并重启统一入口。

平台凭据只留服务端；这个语音会话不会登记房间权限。默认同一时刻一个语音请求，超时或完成就关闭；多人同时使用会提示忙，当前不承诺生产并发。

## 页面使用

轮到本人发言时点击“灵矽录音转写”，授予麦克风权限，录音后点“结束录音”。最长 30 秒；取消会丢弃录音和迟到转写。识别文字填入草稿，检查后才点击“确认并提交发言”。不支持录音、拒绝权限或平台失败时仍可直接输入文字。原有“语音转文字”使用浏览器 ASR，是另一种输入方式。

“启用公共播报”只播放启用后新产生的公开事件，点击停止立即停止；刷新不自动开启或重播历史。音频请求只接收事件 ID，文本由服务端生成，页面不能传任意私密回复。播放前必须收到与指定文本逐段严格一致的 sentence_start 标记及完整 tts.stop，且 PCM 已协商。此校验核对协议元数据，不代表独立识别并证明了音频内容；真实平台验收仍需听检。标点不一致也会拒绝，优先保护输出边界。

依据官方 WebSocket 文档的 listen.detect + text_response，仅用于指定播报，不用作文本推理。服务端不保存原始录音、STT 或 TTS 到日志，不向公共页面广播私人转写。

## 当前验证边界

协议、API 和浏览器取消回调为自动化模拟验证。真实转写、指定播报和完整混合局尚需已激活独立语音 profile，#68 保持开放。当前不实现夜间自然语言动作解析，按按钮选择目标确认。API 仅限本机开发，不应直接暴露到公网；隧道仅代理带认证的 MCP。

## 技能与投票草稿

在本人合法夜间行动、投票或猎人窗口，可录音转写或输入“投给三号玩家”“袭击三号”“查验三号”“使用解药”“毒杀三号”“跳过”“开枪带走三号”“放弃开枪”。页面保守解析，展示“待确认：动作 + 目标”，只有点击“确认此行动”才调用原有游戏接口。含否定、多目标或不明确表达不生成动作，直接改用原有按钮。阶段、房间或控制来源变化会清除草稿。

这些规则并不支持任意口语。真实灵矽 STT 仍由 #68 验收；本地解析与确认测试通过不代表平台语音成功。
