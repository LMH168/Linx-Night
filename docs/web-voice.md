# 网页真人语音

真人普通发言和遗言均使用浏览器 SpeechRecognition（兼容 webkitSpeechRecognition），中文连续识别，与麦克风原声实时广播并行。无需独立灵矽 Agent 或 LINX_VOICE_PROFILE；已有身份不会被删除。

识别文字每约 150ms 合并发送一次，经现有 WebSocket 保存到房间内存，其他真人可以看到更新。结束录音最多等待 1 秒接收识别最后结果，然后以已有文字和原声确认同一条公开记录。AI 行动前通过 get_recent_speeches 的 records 查询确认后的文字；不接收音频来理解内容。发言、遗言使用同一规则，不再等待整段音频上传给灵矽识别。

支持识别的浏览器仍可能使用浏览器厂商的网络服务，并不保证离线或所有浏览器可用。麦克风需要安全上下文（HTTPS 或 localhost）及授权。界面显示识别文字并允许手动修正；一旦手动输入，停止自动识别，避免覆盖修正。没有识别文字时仍保存、广播原声，明确标记未识别并允许原玩家补充文字，AI 不得猜测内容。也可直接使用文字提交。

识别失败会显示提示，不会转入灵矽重试或占用游戏 AI 会话。网络断开时服务器保存已收到的原声与文字；主动取消则丢弃本次记录。房间结束、过期窗口和旧录音不能继续更新当前记录。与现有房间状态一样，实时文字保存在内存，不承诺跨服务器重启恢复。

旧 voice/transcribe 接口仅在测试或显式注入兼容 provider 的开发环境可用，生产统一入口不注入识别 provider。
