# 八席灵矽与独立主持配置（#78）

正式入口自动为全部 AI 空位分配 LINX_PROFILES，不再固定 P2/P3，不执行规则机器人 tick。平台无可用身份时必须重试或取消。

- LINX_PROFILES：按顺序配置八个已激活软件身份，逗号分隔。测试夹具仍可显式限定席位。
- LINX_AGENT_ID：玩家 Agent。
- LINX_HOST_PROFILE、LINX_HOST_AGENT_ID：独立主持软件身份和独立 Agent，不能与玩家或转写身份复用。
- 玩家与主持均绑定同一公网 MCP，使用已有测试认证；权限由后台登记决定。主持 HOST 是控制器标识，不是第十个座位。
- 玩家与主持关闭跨会话记忆，主持只允许读取公开状态、公开发言和 get_host_announcements。
- 初始化软件身份后，在控制台设备激活入口输入激活码并选择对应 Agent。激活码过期重新执行 activate，不删除原 identity.json。

开局需要全部玩家与主持就绪才分配角色。房主可取消失败准备；重启不恢复旧内存房间。死亡不翻牌：猎人窗口只在本人私密 hunterAction 返回，公共页面显示结算中，实际开枪才公开技能。

第一份 PR 只提供身份生命周期、权限和隐私基础；主持公共播放在下一份 PR 接通。真实八席验收未完成前 #78 保持开放。

## 主持播放

统一入口在独立主持连接上使用指定文本播报。网页点击“启用主持声音”后，服务端按公开事件生成一次音频，校验完整文本与 PCM，网页播放结束后确认当前任务。普通行动在播报期间等待；猎人窗口不等待声音。停止声音不会确认完成，重新启用可以继续当前未完成任务。刷新不自动播放历史，待处理任务保留。

主持失败会保留任务并显示重试，房主重试使用新的连接；取消对局释放任务和缓存。音频缓存最多保留 40 条未完成任务，每条最多 60 秒 PCM，已播放即删除；任务历史保留最多 80 条。按任务 ID 获取音频，不接受客户端指定播报文本。

API：GET /api/rooms/:id/host/state；GET /api/rooms/:id/host/audio?task_id=...；POST /api/rooms/:id/host/played（task_id）；POST /api/rooms/:id/host/retry。仅房间真人访问，当前本机房主负责确认播放与重试。多人播放同步属于后续范围。

当前验证为模拟协议/队列/网页事件及九控制器准备。真实主持指定播报和八席身份待激活后验收，不因代码合并声称真实可用。
