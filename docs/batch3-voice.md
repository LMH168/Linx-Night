# 第三批公共语音配置

Refs #79。主持和玩家使用统一队列，仅朗读服务端已经接受的公开内容。玩家原始推理语音不进入播放器。

在仓库外 env 中设置 LINX_HOST_VOICE_ID 和 LINX_PLAYER_VOICES。后者为单行 JSON，例如 {"player-a":"实际音色ID1","player-b":"实际音色ID2"}；所有启用 profile 都必须有配置，主持和玩家 ID 不得重复。音色在准备房间时固定，重连沿用。

官方协议：https://linx.qiniu.com/docs/xrobot/platform/agent-voice-switch 。使用 listen.detect 的 text_response 指定正文，并用 agent_params.voice.id 指定音色。每条任务（含主持）都显式指定音色。

网页只有“启用公共声音”开关。自然结束才确认播放；停止保持当前任务，恢复会重新播放未完成任务。房主可明确跳过当前音频，任务记为 skipped，不会提交玩家行动。播放失败重播缓存，生成失败使用重试生成按钮。

音频最多 60 秒、正文最多 1200 字，待处理队列最多 40 条、保留任务记录最多 80 条。超限失败会暂停普通回合，不截断内容。私密夜间行动和猎人窗口独立运行。

真实平台音色组合与听检尚待验收；配置不同 ID 和协议测试通过不等于实际音色已确认。
