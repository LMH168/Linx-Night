# 暮林山舍启动页、角色牌册与游戏界面原型

## 动态启动页

![暮林山舍动态启动页](./forest-cabin-launcher.png)

启动流程：

1. 进入页面后显示暮林山舍动态森林小屋场景。
2. 镜头完成进入动画。
3. 三位人物从远处石径走到门前。
4. 点击「进入林间」后进入 Linx Night 房间客户端。

## 角色牌册

![狼人杀角色牌册](./werewolf-roster-preview.png)

角色牌册包含 10 位角色：狼人、狼美人、预言家、女巫、猎人、守卫、骑士、村民、白痴、丘比特。

## 游戏内界面换肤

桌面端游戏界面：

![暮林山舍游戏界面](./game-interface-forest-theme.png)

移动端游戏界面：

![暮林山舍移动端游戏界面](./game-interface-forest-theme-mobile.png)

游戏内已完成：

- 深绿、苔色、旧金色和琥珀色背景系统
- 暮林风格卡片、按钮、输入框、选择框和状态标签
- 座位头像替换为角色头像
- 私密身份区域显示对应角色头像和英文角色名
- 启动页与游戏内页面共用同一套角色视觉

## 交互约束

- 启动页动态场景不可显示嵌套的暮林山舍 loader。
- 启动页动画需要保留人物沿石径走向小屋的原始时间线。
- 启动画面需要适配桌面端与移动端。
- 座位头像使用 `public/assets/werewolf/avatars/` 中的角色素材。
- 视觉主色保持月夜蓝绿、苔绿、琥珀灯光与旧金色。
