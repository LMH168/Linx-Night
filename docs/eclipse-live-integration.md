# 月蚀议会正式客户端接入

默认首页 `/` 和 `/game.html` 现在使用月蚀议会界面，复用 `GameApiClient`、Pinia 房间投影、SSE、真人录音转写和主持 PCM 播放队列。原型的本地引擎、演示按钮、角色切换和模拟推进没有进入正式入口。五张角色图来自现有原型素材，无新增项目依赖。

## 页面与操作

- 入口：昵称、创建、加入；刷新后用当前标签页保存的身份恢复房间。
- 大厅：九席状态，房主添加/补齐 AI、改名、开始；加入者等待房主。开始按钮要求九席满员。
- 准备：逐个显示实际 AI/主持控制器状态。失败后房主可重试或取消；重试先释放旧控制器，再发起新的准备。
- 牌桌：服务器决定阶段与行动资格，圆桌与下拉框共享合法目标。本人身份可收起；仅本人和合法狼队友可展示角色插画，出局不自动翻牌。
- 发言：录音→转写草稿→编辑→确认提交；未确认文字不会公开。失败保留当前窗口草稿；切换房间、发言人或响应窗口时清理旧操作。
- 主持：手动启用声音以满足浏览器音频权限；暂停、继续、失败重试和房主跳过均使用真实播放队列。只有房主确认播放完成。
- 异常：SSE 重连并重新获取公私快照；断线/同步期间禁止提交。失败 AI 由房主重试，正常遗言超时不会误判成 AI 连接失败。
- 结算：从授权结算接口加载翻牌、出局顺序、投票与公开发言，可下载 JSON。房主提前结束须确认；房间删除后刷新仍可恢复结算。返回大厅清理旧身份，新一局创建新房间。

## PK 与共享契约

保留 #165 约定的 REST 路径和请求字段。新增的投影字段均为兼容性补充：

| 字段 | 含义 |
| --- | --- |
| `RoomPublicState.pk` | 当前日、`speech`/`vote` 阶段和平票候选席位 |
| `VoteResolution.pk` / `candidates` | 区分同一天首轮与 PK 重投的结算记录 |
| `PrivateState.canAct` | 本人的真实行动资格，刷新后不会重新展示已提交的狼人操作 |
| `PrivateState.werewolfTeammates/wolfProposal/nightVictim` | 明确现有私密字段类型，不进入公开席位 |
| `seerResults.seatId` / `round` | 对齐实际后端查验记录，兼容旧 `targetSeatId` |
| `speechDeadline` | 兼容后端毫秒时间戳及 ISO 时间字符串 |

首次平票：候选人按座位号码递增进行 PK 发言。之后只有台下存活玩家可重投，且只能投候选人；再次平票无人出局，进入下一夜。全员平票导致无人可重投时，记录零票 PK 结算并进入下一夜。两轮提交和结算分开保存；投票结束前只公开已投席位。

AI 行动租约、MCP 必须执行的投票目标、规则机器人、预连接下一位发言人、主持文本及玩家/主持提示同步适配 PK。PK 真人发言使用新的 30 秒窗口，超时提交编号与同一天普通发言区分。猎人行动以本人私密窗口判断，其他玩家继续只看到 `RESOLUTION`。

## 本机运行

在本工作目录安装与构建，使用原有仓库外环境文件启动：

```powershell
npm.cmd ci
npm.cmd run build:client-vue
node scripts/start-local.mjs "$env:LOCALAPPDATA\LinxNight-runtime.env"
```

现有 Windows 环境示例使用网页 5110、API 5100、MCP 9191。公网客户端继续使用同源 API；本地非标准 API 地址可通过 `?api=http://127.0.0.1:端口` 覆盖。每次修改界面后重新构建；启动脚本只会在缺少构建目录时自动构建。静态服务器默认构建目录已对齐 `apps/client-vue/dist`，也支持原来的 `CLIENT_DIST` 覆盖。
